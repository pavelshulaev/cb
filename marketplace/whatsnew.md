## Текст для вкладки

**Панель версии и полезных ссылок в настройках.** На странице настроек модуля
появилась плашка с проверкой актуальности установленной версии (сверяется с
Маркетплейсом) и панель кнопок: «Оставить отзыв», «Задать вопрос», «Заказать
доработку», «Другие модули» — форма техподдержки на rover-it.me открывается
с уже заполненной темой обращения.

**Исправлено отображение статуса подключения.** На вкладке настроек из-за
ошибки в коде метка рядом с названием вкладки всегда показывала «есть
подключение», даже если подключения к «Клиентской базе» не было.

**Исправлена проверка зависимостей при установке.** Сообщения об ошибках
(неподходящая версия PHP, версия «Главного модуля», отсутствие mod_rewrite)
не отображались при установке из-за расхождения путей и ключей локализации.

**Усилена защита соединения с «Клиентской базой».** Проверка TLS-сертификата
сервера была отключена для всех запросов к API — включена обратно.

**Исправлен путь к файлу лога.** Лог модуля писался в папку другого модуля
вместо своей — теперь корректно попадает в `/upload/rover.cb/log/`.

**Совместимость с PHP 8.2.** Устранены предупреждения уровня deprecated,
мешавшие работать на актуальных версиях PHP.

**Повышены минимальные требования.** PHP 8.1+ и «Главный модуль» версии
24.0.0+; заодно исправлена сама проверка версии «Главного модуля» при
установке — раньше сравнение версий работало некорректно.

## Заметки по правке

- Версия 1.2.0 уже проставлена в `install/version.php` (дата 14.08.2026) —
  не мной в рамках этой сессии, но черновик ориентируется на неё. Минорная,
  не патч: есть новая функциональность (панель версии/кнопок), не только фиксы.
- Пункт про PHP 8.2 покрывает: динамическое свойство без объявления в классе
  установщика, публичность магического метода `__wakeup()`, передачу `null`
  во внутренние строковые функции.
- Пункт про TLS покрывает: было жёстко закодировано `disableSslVerification
  => true` для HttpClient — убрано.
- «Расхождение путей и ключей локализации» — установщик ссылался на
  несуществующий `lib/config/dependence.php` и класс `Config\Dependence`
  (переехал в `lib/service/dependence.php`/`Service\Dependence`), а языковые
  ключи ошибок были скопированы с префиксом `rover_acrm__` от rover.amocrm
  вместо `rover-cb__` — из-за этого `Loc::getMessage()` не находил строку.
- Баг с `version_compare()` без оператора сравнения (сравнивал версии только
  на точное равенство) нашёл и исправил я сам при сборке этого черновика —
  раньше его никто не просил чинить, но публиковать changelog с описанием
  «исправлена проверка версии» при реально сломанной проверке было бы
  враньём, поэтому поправил заодно.
- README.md переписан под фактический код (актуальные классы, методы,
  требования) — решил не выносить отдельным пунктом, это внутренняя
  документация, не пользовательская функциональность.
- `reports/` и `security-journal.json` в рабочей копии — результат
  security-аудита модуля, для внутреннего процесса Маркетплейса, не тема
  для этого текста.
- Для rover.cb (в отличие от rover.amosale) ещё нет `marketplace/description.md` —
  этот файл только про «Что нового», карточку решения отдельно не готовил.
